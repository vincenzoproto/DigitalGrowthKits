# DigitalGrowthKits

Digital products for hospitality and small accommodation businesses.

Built as a lightweight Next.js storefront inspired by the TishCommerce approach: JSON catalog, no database, digital-first checkout architecture.

## Initial catalog
- Hospitality AI Kit — €29
- Airbnb Host Kit — €39
- 100 Instagram Templates — €19
- Hotel Sales Email Pack — €29
- B&B Low Season Kit — €59
- Complete Hospitality Bundle — €99
