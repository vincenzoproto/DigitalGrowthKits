# GuestFlow Systems

Done-for-you hospitality software implementations built on proven open-source foundations.

The public brand is **GuestFlow Systems**. The GitHub repository keeps its historical repository name for continuity, but the storefront, product pages and customer-facing material use the new brand.

## Current offers
- Guest Inbox Pro — €690 setup
- Digital Guest Concierge — €490 setup
- Repeat Guest Engine — €990 setup
- Direct Booking Engine — €1,490 setup

These are implementation services, not downloadable template packs. The customer pays for configuration, deployment, workflow design, handover and optional managed support.

## Repeat Guest Engine
Based on the Mautic marketing-automation foundation. The delivery package includes:
- guest database mapping from CSV / PMS export
- marketing eligibility and suppression mapping
- hospitality segments
- post-stay, win-back and low-season workflows
- preference/unsubscribe handling
- reporting and staff handover

Mautic is GPLv3. GuestFlow Systems sells implementation, hosting/configuration and support while respecting the upstream license and trademark requirements.

## Guest Inbox Pro
Based on Chatwoot community/core capabilities with hotel-specific inbox structure, labels, routing, canned replies and staff handover.

## Digital Guest Concierge
Inspired by AtlasQR's MIT-licensed multi-tenant QR/catalog foundation, verticalised into a hotel/B&B guest portal.
